# C Day 95 - Electricity Bill Management System

## Description
An Electricity Bill Management System developed using C. It calculates electricity bills based on the number of units consumed and stores customer records in a text file.

## Features
- Add customer electricity bills
- Calculate bills using unit-based rates
- Display all customer records
- Search customers by ID
- Store records permanently

## Billing Rates
- First 100 units: Rs. 3 per unit
- Next 100 units: Rs. 5 per unit
- Above 200 units: Rs. 7 per unit

## Files
- `electricity.c` - Main C program
- `bills.txt` - Customer billing records

## How to Compile
`gcc electricity.c -o electricity`

## How to Run
Windows: `electricity.exe`

Linux: `./electricity`

Keep `bills.txt` in the program's working directory.
